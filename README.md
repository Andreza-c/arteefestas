# 🎉 CRM Arte & Festas

Sistema de gerenciamento desenvolvido para auxiliar no controle e na organização de uma empresa de decoração de festas.

O **CRM Arte & Festas** tem como objetivo facilitar a administração das peças para aluguel, dos temas de decoração e da disponibilidade dos itens conforme as datas das locações.

## ✨ Funcionalidades

- Cadastro e gerenciamento de temas de decoração.
- Organização de peças e itens por tema.
- Controle de quantidade de itens disponíveis.
- Gerenciamento de locações por data.
- Consulta da disponibilidade dos temas para cada período.
- Organização das informações dos clientes e das locações.

## 🎈 Organização do estoque

O sistema utiliza uma organização baseada em **temas de decoração**, como:

- Safari
- Princesas
- Futebol
- Jardim Encantado

Cada tema possui suas próprias peças e quantidades cadastradas, permitindo acompanhar a disponibilidade do conjunto para novas locações.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo do projeto

Desenvolver uma solução digital para otimizar a gestão de uma empresa de decoração de festas, reduzindo controles manuais e facilitando o acompanhamento do estoque e das reservas.
